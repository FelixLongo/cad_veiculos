Sistema de Cadastro de Veículos (PHP)

Este é um projeto simples desenvolvido em PHP para gerir o registo de veículos. 
O sistema permite realizar as operações básicas de um CRUD (Criar, Ler, Atualizar e Eliminar).

Funcionalidades
Cadastro: Inserir novos veículos através do ficheiro `processa.php`.
Listagem: Visualizar todos os veículos registados em `listar.php`.
Edição/Atualização: Modificar dados existentes em `editar.php` e `atualizar.php`.
Exclusão: Remover registos através de `excluir.php`.

Tecnologias Utilizadas
PHP: Lógica do lado do servidor.
HTML/CSS: Estrutura e estilização visual (`style.css`).
MySQL: Base de dados para armazenamento (configurada em `conexao.php`).

Como configurar
1. Importe a sua base de dados MySQL.
2. Configure as credenciais de acesso no ficheiro `conexao.php`.
3. Coloque os ficheiros num servidor local (como XAMPP ou WampServer).
4. Aceda através de `localhost/cad_veiculos/index.html`.
